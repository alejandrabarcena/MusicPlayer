# Music Player 🎵🎹

## Descripción General

**Music Player** es una aplicación de escritorio desarrollada en **Python** que permite reproducir, organizar y gestionar colecciones musicales mediante una interfaz gráfica intuitiva construida con Tkinter.

La aplicación integra funciones avanzadas como gestión de playlists, control de reproducción, ajuste de volumen, extracción de metadatos y búsqueda especializada de música clásica mediante la API de MusicBrainz.

El proyecto fue desarrollado como una práctica de programación orientada a interfaces gráficas, procesamiento multimedia y consumo de APIs externas.

---

# ✨ Características Principales

- Reproducción de archivos de audio
- Gestión de playlists
- Control de volumen en tiempo real
- Navegación entre pistas
- Búsqueda de música clásica
- Extracción automática de metadatos
- Soporte para múltiples formatos de audio
- Interfaz gráfica amigable
- Persistencia de listas mediante archivos JSON

---

# 🎼 Búsqueda de Música Clásica

La aplicación incorpora integración con **MusicBrainz**, permitiendo:

- Buscar compositores
- Consultar obras musicales
- Explorar grabaciones
- Filtrar por períodos históricos
- Descubrir nueva música clásica

Períodos disponibles:

- Barroco
- Clásico
- Romántico
- Moderno

---

# 🎧 Formatos Compatibles

Actualmente soporta:

- MP3
- WAV
- OGG

La arquitectura permite añadir nuevos formatos de forma sencilla.
